# Documentación de la Página Web

## Nombre del sitio
Vitality Lab – Suplementos Naturales

---

# Descripción General

Vitality Lab es una página web estática creada con el objetivo de presentar y promocionar suplementos vitamínicos y productos naturales relacionados con el bienestar y la salud.

La página fue diseñada para transmitir confianza, tranquilidad y profesionalismo mediante un diseño limpio, colores suaves y una navegación sencilla. La idea principal es que el usuario sienta que está entrando a un sitio serio y enfocado en mejorar su calidad de vida, no simplemente a una página de ventas agresiva.

---

# Objetivo de la Página

El propósito del sitio es permitir que los usuarios puedan conocer suplementos naturales según sus necesidades personales, como mejorar el descanso, reducir el estrés, aliviar molestias musculares o complementar su bienestar diario.

La página busca facilitar la exploración de productos de manera clara y organizada.

---

# Diseño Visual

Para el diseño se utilizaron principalmente tonos verdes suaves, blancos y colores claros para representar naturalidad y bienestar.

Se evitó utilizar colores demasiado fuertes o elementos visuales exagerados para mantener una apariencia relajante y profesional.

El diseño general intenta transmitir:

- confianza
- limpieza
- calma
- naturalidad
- profesionalismo

---

# Estructura del Sitio

La página cuenta con una barra de navegación superior que permite acceder rápidamente a las diferentes secciones del sitio.

Las secciones principales son:

- Inicio
- Productos
- Categorías
- Testimonios
- Quiénes somos
- Contacto

---

# Página Principal

La pantalla principal muestra un producto destacado junto con una pequeña descripción y botones de navegación.

También se muestran reseñas de clientes para generar mayor confianza en los visitantes y hacer que el usuario se sienta más seguro sobre los productos.

---

# Categorías

Los productos se organizan según necesidades comunes de los usuarios, por ejemplo:

- descanso y sueño
- relajación
- energía
- salud muscular
- bienestar general

Esto permite que el usuario encuentre más fácilmente productos relacionados con el problema o necesidad que desea mejorar.

---

# Productos

Cada producto tiene:

- imagen
- nombre
- breve descripción
- beneficio principal
- botón de acción

La información se mantiene sencilla para evitar saturar visualmente la página.

---

# Adaptabilidad

La página fue diseñada para funcionar tanto en computadoras como en dispositivos móviles, manteniendo una estructura ordenada y fácil de navegar en diferentes tamaños de pantalla.

---

# Tecnologías Utilizadas

Para el desarrollo de la página se utilizaron:

- HTML
- Tailwind CSS
- Google Fonts
- GitHub Pages

El diseño inicial fue generado utilizando Google Stitch.

---

# Publicación

La página fue publicada utilizando GitHub Pages para poder acceder al sitio desde internet de manera gratuita.

---

# Conclusión

Vitality Lab es una página web enfocada en transmitir bienestar y confianza mediante un diseño moderno, limpio y organizado. El sitio busca ofrecer una experiencia agradable para usuarios interesados en suplementos naturales y hábitos de vida saludables.
